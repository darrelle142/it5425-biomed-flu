CÁCH LƯU FILE (áp dụng cho mọi lần tải)
======================================================================
- Lưu vào: data/raw/<nguồn>/<YYYY-MM-DD>/  (YYYY-MM-DD = ngày tải), KHÔNG ghi đè file cũ.
  Tên thư mục <nguồn>: nước thải = cdc_wastewater_wval, vaccine = cdc_fluvax_coverage,
  Gazetteer = census_gazetteer.
  Ví dụ: data/raw/cdc_wastewater_wval/2026-11-07/CDC_Wastewater_Viral_Activity_Level_..._20261107.csv
- Giữ nguyên tên file CDC đặt.
- Sau khi lưu, chạy: python scripts/register_manual.py --by "Tên người tải"
  Script ghi file vào data/raw/manifest.jsonl (ngày tải, người tải, kích thước, sha256).
- Lý do: file CDC không có lịch sử phiên bản, nên phải lưu từng bản mới biết số liệu bị sửa thế nào.
